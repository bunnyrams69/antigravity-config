# Editorial Video Prompt Engine: Reverse-Engineered Reel Framework

## 1. System Overview

This skill reverse-engineers the **Cinematic Editorial Poster** video editing architecture into an automated, deterministic JSON prompt generator for video-to-video AI systems (Google Omni Flash, Seedance, Runway Gen-3) and automated NLE pipelines (Premiere Pro, After Effects, CapCut).

### Core Visual Aesthetics:
1. **Behind-Subject Depth Typography**: Large, high-contrast Serif keywords placed in the 3D Z-plane behind the rotoscoped speaker.
2. **Editorial Vertical Margin Rails**: Micro-credit text running along the left (90°) and right (270°) borders mimicking high-fashion / cinematic editorial posters.
3. **35mm Warm Film Color Grade**: Golden amber highlights, deep rich blacks, muted teal shadows, and subtle organic film grain.
4. **Kinetic Camera Framing**: Alternating 100% A-roll center locks with 110%–118% snap zooms and slow forward pushes synced to speech emphasis.
5. **Layered Sound Design**: Heavy cinematic sub-booms, mechanical clock ticks, digital UI chirps, glitch risers, and trailing reverb tails.

## 4. Prompt Construction Rules & Guidelines

### Rule 1: Typography Hierarchy & Positioning
- **Behind-Subject Title (`main_title`)**:
  - Maximum **1 to 2 words** per segment (e.g., `MANUAL`, `2 HOURS`, `SYSTEM`, `AUTO`, `3 MINS`, `SCALE`).
  - Font: Heavy high-contrast **Serif** (Bodoni, Playfair Display, Didot).
  - Color: Signature **Editorial Red** (`#E50914`).
  - Layering: Masked behind the speaker's foreground matte using AI rotoscoping / depth map.
  - Scale: **220% to 270%** (oversized, bleeding slightly off screen edges).

- **Lower Subtitles (`subtitle`)**:
  - Direct translation or supporting punchline in clean Sans-Serif (`#FFFFFF` or accented `#00FF66` / `#00E5FF` / `#FFCC00`).
  - Position: Lower-third, centered, never overlapping speaker's chin.

- **Vertical Margin Rails (`border_credits`)**:
  - Left rail: Running bottom-to-top (`transform: rotate(-90deg)`).
  - Right rail: Running top-to-bottom (`transform: rotate(90deg)`).
  - Content: Editorial credits, brand labels, or technical specs separated by bullets (`•`).

### Rule 2: Framing & Motion Cuts
- **Segment 1 (Hook)**: Start with `A-roll (100% scale)` for 0.8s–1.2s to establish the speaker, then hit a **`112% Snap Zoom`** on the pain point.
- **Segment 2 (Feature Breakdown)**: Alternate between `110% Zoom` and `115% Zoom` every 1.0s–1.5s to maintain viewer retention.
- **Segment 3 (Climax / CTA)**: Use `118% Zoom-in (Slow continuous push)` resolving into a locked poster-frame hold.

### Rule 3: Sound Design Formula (SFX)
Always pair visual actions with corresponding acoustic layers:
1. **Scene Open / Hook**: Low sub-bass drop (`40Hz - 80Hz`) + heavy cinematic impact thud.
2. **Time / Pain Points**: Fast mechanical analog clock ticking or tape stop.
3. **AI / System Tech**: Sci-fi powerup hums, digital scan beeps, or data ripple whooshes.
4. **Speed / Dispatch**: Triple rapid UI pop chimes + air swooshes.
5. **Money / Results**: Cash register ding, air horn accent, or coin chime.
6. **Closing Poster Hold**: Cinematic sub-boom with long acoustic reverb tail.

## 5. Execution Recipe for Generating Prompts

When given input video clips or dialogue transcripts:

```
[Input Videos (e.g. clip1.mp4, clip2.mp4, clip3.mp4)]
                   │
                   ▼
┌───────────────────────────────────────────────┐
│ 1. Extract audio & transcribe timestamps      │
│ 2. Segment into 10.0s timeline (3 distinct    │
│    parts: Problem → Solution → Payoff)        │
│ 3. Assign 1 dominant keyword per beat         │
│ 4. Generate depth masks & margin credit texts │
│ 5. Map framing zooms (100% → 115% → Push)     │
│ 6. Sync layered SFX cues to millisecond marks │
└───────────────────────────────────────────────┘
                   │
                   ▼
[Output: Pure Valid JSON Prompt Sequence]
```

### Step-by-Step Workflow:
1. **Identify the 3 Source Clips**: Map to Problem (Part 1), Solution (Part 2), Proof/CTA (Part 3).
2. **Calculate Precise Timecodes**: Total runtime 10.0s standard (`00:00:00.000` to `00:00:10.000`). Frame rate standard: 30fps.
3. **Isolate Dialogue**: Preserve exact spoken dialogue word-for-word in `dialogue`.
4. **Apply Behind-Subject Keyword**: Extract exactly 1–2 punchy words for `main_title.text` (uppercase, bold serif).
5. **Compose Vertical Margins**: Create high-concept uppercase editorial credit rails.
6. **Layer SFX Timing**: Every segment must specify auditory impact synced to millisecond timestamps.
7. **Validate JSON**: Ensure the output is 100% valid JSON matching the schema.
